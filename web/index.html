Pick the buff skills you use and their level: your job's skills come first, then party buffs from other jobs. Skills whose text is a plain stat are counted; the rest are listed. For food or items, type the stat (5 for 5%). Read your character screen without these buffs on.

Runes (crystals)

5 runes per side. Main effects marked "dmg" change damage; the ones that only work in some fights (target HP below 20%, stationary, abnormal status…) start switched off, so tick "count" if it fits your fight. Resonance counts every colour of all 5 runes: 2, 4 and 7 of one element light a tier, and only the highest tier counts.

Every possible result

These odds follow rtnw.online's model: each position comes from the main or the material card, weighted by affix tier (green 40,000, blue 20,000, purple 10,000, so the lower tier is more likely); fixed effects are 50/50. The game's real rule is not public. Each fusion uses up the material card. How many Spirit Pieces a fusion takes is not in the data, so type it from the game (a Spirit Piece costs 2 Bound Starstones).
